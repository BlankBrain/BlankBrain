### Hi, I'm Mehedi.

I'm an agentic engineer in Dhaka. In June 2025 I started [Karigor AI Labs](https://github.com/Karigor-AI-Labs), an agentic engineering lab. We design AI agents for organizations whose people speak Bangla, test them before they ship, run them in production, and keep improving them.

Karigor means craftsman. Each agent we build is a karigor: it learns one job, works under written rules, and hands the work to a person where those rules say so.

**What we measure**

- 13 karigors built and run on our own platform, as of 4 October 2026.
- Changes to our agents are scored on KarigorBench, our own test bench, before they ship: 313 test cases in 12 suites, as of 13 October 2026.

**Free for anyone: Karigor Skills**

Every karigor is engineered from skills: a written procedure, rules, and test cases it has to pass. We give the skills away, packaged for ChatGPT, Gemini and Claude, each with its own test suite. Free under CC BY 4.0.
[github.com/Karigor-AI-Labs/karigor-skills](https://github.com/Karigor-AI-Labs/karigor-skills)

One rule we keep: we describe what an agent did, never what it might do.

Before Karigor I spent five years building iOS apps. The older repositories here are from those years.
